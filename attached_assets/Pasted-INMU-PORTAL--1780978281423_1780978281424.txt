① 管理者ナビゲーション時のログアウト不具合
━━━━━━━━━━━━━━━

現在、管理者ログイン後に以下をタップするとログアウトされ、通常ユーザーのログインページへ飛ばされます。

発生箇所

・プロフィールタブ
・管理ツールタブ
・下部ナビゲーション切り替え時

修正内容

・管理者セッションと通常ユーザーセッションを正しく分離
・管理者ログイン中は、プロフィール / 管理ツール / Users / Actions / Audit を移動してもログアウトしない
・管理者セッション期限は5分のまま維持
・5分以内の操作中はログアウトしない
・期限切れ時のみ再ログイン要求
・通常ユーザーが管理画面へアクセスした場合のみ拒否

確認項目

・管理者ログイン後、プロフィールへ移動してもログアウトされない
・管理者ログイン後、管理ツールへ移動してもログアウトされない
・Users / Actions / Audit 切替でログアウトされない
・5分経過後のみセッション切れになる
・通常ユーザーは管理ツールへ入れない

② ミッション達成フロー修正
━━━━━━━━━━━━━━━

現在、ミッションの達成・受取フローが不十分です。

基本仕様

ミッションは以下の流れにしてください。

1. 参加する
2. 条件達成
3. 報酬を受け取る

「参加する」を押す前は、達成ボタン・受取ボタンを押せないようにしてください。

⸻

リンク付きミッションの場合

1. 参加する
2. 外部リンクを開く
3. リンクを踏んだ時点で達成扱い
4. サイトへ戻ったら報酬受取可能

表示例

未参加
→ [参加する]

参加後
→ [リンクを開く]

リンククリック後
→ [報酬を受け取る]

受取後
→ [受取済み]

⸻

リンクなしミッションの場合

1. 参加する
2. 達成する
3. 報酬を受け取る

表示例

未参加
→ [参加する]

参加後
→ [達成する]

達成後
→ [報酬を受け取る]

受取後
→ [受取済み]

⸻

重複受取防止

・デイリーミッションは1日1回のみ受取可能
・ウィークリーミッションは1週間1回のみ受取可能
・同期間中の再受取は禁止

③ ユーザー間INMU送金追加
━━━━━━━━━━━━━━━

一般ユーザー同士でINMU送金を可能にしてください。

送金元

・ログイン中ユーザー

送金先検索

・ユーザー名
・SOLアドレス
・X ID
・Discord ID

送金内容

・送金量
・任意メモ

送金時認証

・送金パスコード必須
・Phantom署名必須

送金条件

・送金元ユーザーがPhantom接続済み
・送金元ウォレットに十分なINMU残高がある
・送金先ユーザーにSOLアドレスが登録済み

送金後

・送金元履歴に「INMU送金」
・送金先履歴に「INMU受取」
・TxHash保存
・Solscanリンク表示
・累計送金額へ反映
・累計受取額へ反映

注意

・ポイント送金はユーザー間では不要
・まずはINMU送金のみ実装
・管理者送金機能は維持
・複数送金、一括送金は維持

④ GitHubコミット運用
━━━━━━━━━━━━━━━

修正完了後は必ず以下を実施してください。

1. GitHubへコミット
2. GitHubへPush
3. コミットIDを報告
4. 変更ファイル一覧を報告
5. 変更内容一覧を報告
6. その後にのみPublish可能

完了報告時に必須

・Commit Hash
・変更ファイル一覧
・変更内容一覧
・Production反映対象コミット

例

Commit:
a1b2c3d

変更ファイル:

* dashboard-view.tsx
* admin-panel.tsx
* mission-service.ts

変更内容:

* ユーザー間送金追加
* ミッションフロー修正
* 管理者セッション修正

━━━━━━━━━━━━━━━
⑤ Publishルール
━━━━━━━━━━━━━━━

Publish前に必ず以下を報告してください。

・修正完了
・GitHub Push完了
・コミットID
・影響範囲
・確認項目

ユーザー確認後にのみPublishしてください。

勝手にPublishしないでください。

⑥ 巻き戻り防止
━━━━━━━━━━━━━━━

GitHub同期時に古いコミットで上書きしないようにしてください。

現在作業中ブランチとProduction対象ブランチが一致していることを確認してください。

Publish対象コミットを毎回明示してください。

修正済み機能が消えていないことを確認してからPublishしてください。
